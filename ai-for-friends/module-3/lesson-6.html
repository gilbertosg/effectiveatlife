Using Your Project to Design More Projects

Once one Project works, let Claude draft the setup for the next one.

10 MIN REQUIRED
1. Have Claude Design It 2. Pick Your Next Project

By the end of this lesson, you will use a working Project to design your next one. Once your first Project works well, you do not start the second from scratch. You ask Claude to draft the name, description, instructions, and file list for you.

A working Project already knows your role and your formatting preferences. That makes it the best tool for designing the next Project, because its suggestions arrive pre-fitted to how you work. You get a complete setup to paste in, instead of a blank instructions field to fill alone.

1Have Claude Design the Next Project

Your first working Project can design your next one. Ask it for the full setup in a pasteable format, and it drafts the name, description, custom instructions, and reference-file list for you.

  1. Open your existing, working Project.
  2. Start a new chat inside it.
  3. Paste the prompt below, editing the goal to match the Project you want.
  4. Read the four-part setup Claude returns.

The Design Prompt

I want a new Project that drafts weekly status summaries for my team.
Design it for me. Give me the exact: (1) Project name, (2) short
description, (3) custom instructions, and (4) a list of reference
documents I should upload as Project knowledge. Write the custom
instructions so I can paste them straight into a new Project.
Why This Works

A working Project already knows your role and your formatting preferences. Its suggestions for the next Project arrive pre-fitted to how you work, so you edit rather than start from nothing.

Ask Inside Your Existing Project

Run this prompt inside a Project you have already set up, not in a blank chat. The setup it drafts will match the style and format you already use.

2Pick Your Next Project

The design prompt works best with a clear target. This step gives you five proven Project ideas. Pick one, run the prompt from Step 1, and build it using the lessons you have already completed.

  1. Pick one Project from the table below.
  2. Run the Step 1 design prompt with that Project as the goal.
  3. Create the Project, following Lesson 3.3.
  4. Upload the suggested files, following Lesson 3.4.
Project NamePurposeWhat It Would Need
Weekly-ReporterTurns your notes into a weekly status summaryYour status-report template as Project knowledge
Feedback-TrackerSpots recurring themes in client or employee feedbackA folder of past feedback notes to reference
Template-FinderHelps you pick and fill the right document templateAll your standard templates uploaded as knowledge
Deadline-MonitorFlags approaching filing or campaign deadlines you paste inYour standing deadline rules in the custom instructions
Meeting-SummarizerTurns meeting notes into action itemsYour preferred action-item format in the instructions
Nonconformance-TrackerSpots recurring defect types across nonconformance reports (Industrial Engineering)A folder of past nonconformance reports and your report format
Cable-DigestTurns incoming cables or agreements into a briefing-ready summary (International Relations)Your briefing-memo template and priority-topics list
Build One, Not Five

Pick a single Project and set it up completely before starting another. One finished Project you use beats five half-built ones you do not.

Verification

You have run the design prompt and received a complete four-part setup
You have created at least one additional Project from that setup
Not Working?

If the setup Claude returns is generic, run the prompt inside your existing working Project rather than a blank chat. Step 1 explains why that matters.

Lesson complete

You now use a working Project to design the next one, turning one good setup into a whole shelf of assistants. Open your working Project, run the design prompt for your next idea, and create it before you close the tab — momentum is easiest to keep while the first Project is fresh.
