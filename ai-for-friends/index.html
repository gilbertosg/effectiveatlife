How to Use This Course

Go in order. Module 1 defines terms every later lesson assumes you know. Don't skip it.

Module 2 is optional. It's a warm-up for the terminal and VS Code. If both already feel familiar, jump straight to Module 3.

Practice as you go. Every lesson includes prompts you can run immediately in Claude. Open claude.ai and actually run them.

Module 4 goes further. Once Claude Code and Claude Projects (Module 3) feel comfortable, automate one recurring workflow (Module 4).
