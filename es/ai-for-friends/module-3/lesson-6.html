Usa tu Proyecto para Diseñar Más Proyectos

Una vez que un Proyecto funciona, deja que Claude redacte la configuración del siguiente.

10 MIN OBLIGATORIO
1. Haz que Claude lo Diseñe 2. Elige tu Próximo Proyecto

Al terminar esta lección, usarás un Proyecto que ya funciona para diseñar el siguiente. Una vez que tu primer Proyecto funciona bien, no empiezas el segundo desde cero. Le pides a Claude que redacte el nombre, la descripción, las instrucciones y la lista de archivos por ti.

Un Proyecto que ya funciona conoce tu rol y tus preferencias de formato. Eso lo convierte en la mejor herramienta para diseñar el siguiente Proyecto, porque sus sugerencias llegan ya ajustadas a tu forma de trabajar. Obtienes una configuración completa lista para pegar, en lugar de un campo de instrucciones en blanco que llenar solo.

1Haz que Claude Diseñe el Siguiente Proyecto

Tu primer Proyecto en funcionamiento puede diseñar el siguiente. Pídele la configuración completa en un formato listo para pegar, y él redacta el nombre, la descripción, las instrucciones personalizadas y la lista de archivos de referencia por ti.

  1. Abre tu Proyecto existente que ya funciona.
  2. Inicia un chat nuevo dentro de él.
  3. Pega el prompt de abajo, editando el objetivo para que coincida con el Proyecto que quieres.
  4. Lee la configuración de cuatro partes que Claude te devuelve.

El Prompt de Diseño

Quiero un nuevo Proyecto que redacte resúmenes semanales de estado
para mi equipo. Diséñalo por mí. Dame exactamente: (1) el nombre del
Proyecto, (2) una descripción corta, (3) las instrucciones
personalizadas, y (4) una lista de documentos de referencia que debería
subir como conocimiento del Proyecto. Escribe las instrucciones
personalizadas para que pueda pegarlas directamente en un Proyecto
nuevo.
Por Qué Funciona Esto

Un Proyecto que ya funciona conoce tu rol y tus preferencias de formato. Sus sugerencias para el siguiente Proyecto llegan ya ajustadas a tu forma de trabajar, así que editas en lugar de partir de la nada.

Pregunta Dentro de tu Proyecto Existente

Ejecuta este prompt dentro de un Proyecto que ya hayas configurado, no en un chat en blanco. La configuración que redacte coincidirá con el estilo y formato que ya usas.

2Elige tu Próximo Proyecto

El prompt de diseño funciona mejor con un objetivo claro. Este paso te da cinco ideas de Proyecto ya probadas. Elige una, ejecuta el prompt del Paso 1, y constrúyela usando las lecciones que ya completaste.

  1. Elige un Proyecto de la tabla de abajo.
  2. Ejecuta el prompt de diseño del Paso 1 con ese Proyecto como objetivo.
  3. Crea el Proyecto, siguiendo la Lección 3.3.
  4. Sube los archivos sugeridos, siguiendo la Lección 3.4.

Construye Uno, No Cinco

Elige un solo Proyecto y configúralo por completo antes de empezar otro. Un Proyecto terminado que usas vale más que cinco a medio construir que no usas.

Verificación

Has ejecutado el prompt de diseño y recibido una configuración completa de cuatro partes
Has creado al menos un Proyecto adicional a partir de esa configuración
¿No Funciona?

Si la configuración que devuelve Claude es genérica, ejecuta el prompt dentro de tu Proyecto existente que ya funciona, en lugar de un chat en blanco. El Paso 1 explica por qué eso importa.

Lección completada

Ahora usas un Proyecto que ya funciona para diseñar el siguiente, convirtiendo una buena configuración en todo un estante de asistentes. Abre tu Proyecto que ya funciona, ejecuta el prompt de diseño para tu próxima idea, y créalo antes de cerrar la pestaña — el impulso es más fácil de mantener mientras el primer Proyecto está fresco.
