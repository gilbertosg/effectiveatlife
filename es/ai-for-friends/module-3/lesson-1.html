Guía de Inicio de Claude Code

PARA PROFESIONALES DE MARKETING, RR. HH., LEGAL, INGENIERÍA INDUSTRIAL Y RELACIONES INTERNACIONALES — WINDOWS O MAC + VS CODE + CLAUDE PRO

35–45 MIN OBLIGATORIO
0. Antes de Empezar 1. Web vs. Código 2. Instalación 3. Fundamentos de la Terminal 4. Tu Primera Tarea 5. Qué Sigue

0Antes de Empezar

Qué es Claude Code: un asistente de IA que trabaja directamente con los archivos y carpetas de tu computadora. Le hablas en lenguaje cotidiano; él lee, redacta, edita y organiza documentos reales.

Qué es VS Code: la ventana donde sucede todo esto. Piénsalo como Microsoft Word, pero diseñado para abrir una carpeta completa de archivos a la vez, en lugar de un solo documento. VS Code es la oficina; Claude Code es el asistente que trabaja en ella.

Confidencialidad — lee esto primero

Claude Pro es una suscripción personal sin acuerdo de datos corporativo, supervisión administrativa, registros de auditoría ni controles de retención. Practica con material no sensible. Antes de procesar archivos reales de clientes, expedientes de empleados o material privilegiado, consulta con TI/Legal de tu empleador — es posible que requieran Claude Team/Enterprise en lugar de un plan Pro personal.

Costo: Claude Pro, ~$20/mes (~$17/mes con facturación anual). El nivel gratuito no incluye Claude Code — suscríbete antes de tu sesión. Tiempo necesario: ~35–45 minutos. Cómo se ve el éxito: al final, tendrás Claude Code funcionando en tu propia terminal y le habrás hecho producir un trabajo real y guardado — sin copiar ni pegar.

No Puedes Dañar tu Computadora

Claude pide permiso antes de cambiar cualquier cosa, y te muestra exactamente qué planea cambiar.

Lista de requisitos previos

Windows 10 (compilación 1809 o superior) o Windows 11, o macOS 12 o posterior
4 GB o más de RAM
Plan Claude Pro activo (claude.ai)
Credenciales de inicio de sesión de Claude a la mano
Capacidad de instalar software en la computadora
Una carpeta con documentos de práctica no confidenciales

1Web vs. Claude Code — ¿Cuál Uso?

Responde una pregunta: ¿necesitas trabajar con archivos y carpetas, o solo hacer una pregunta?

Si tú...Usa esto
Tienes una pregunta rápida, sin archivos de por medioclaude.ai (web)
Necesitas editar o crear UN solo archivo de Word/Excel/PowerPointClaude Cowork
Necesitas trabajar con MUCHOS archivos, o repetir la misma tareaClaude Code (esta guía)
La Diferencia Central, en Una Oración

La versión web es una conversación sobre tus documentos. Claude Code trabaja sobre tus documentos.

Nueve ventajas concretas

  • Carpetas completas, no una subida a la vez — apúntalo a una carpeta con 40 contratos o 200 currículums
  • El resultado llega como archivos reales y guardados — sin copiar y pegar de una ventana de chat a Word
  • El trabajo masivo se convierte en una sola instrucción — por ejemplo, "extrae la fecha de terminación de cada uno de estos 60 acuerdos en una sola tabla"
  • Recuerda tu proyecto — un archivo CLAUDE.md guarda tu estilo interno, tono o términos definidos en todas las sesiones
  • Ves exactamente qué cambió — cada edición es un "diff" antes/después que apruebas o rechazas
  • Flujos de trabajo repetibles y guardados — convierte una tarea recurrente en un proceso reutilizable
  • Trabajo de varios pasos en una sola pasada — lee, compara, señala y resume en una sola solicitud
  • Los archivos quedan acotados a lo que abres — tú controlas exactamente qué puede ver
  • Funciona con tu estructura de carpetas existente — sin un sistema de archivo paralelo

Cuándo la versión web es realmente mejor: preguntas puntuales rápidas sin archivos, trabajar desde tu teléfono, hacer lluvia de ideas en voz alta, análisis de imágenes o capturas de pantalla, o cuando simplemente no quieres abrir una terminal hoy.

Un Marco Honesto

La web para pensar. Claude Code para producir. La mayoría de las personas usa ambas. El único costo de Claude Code es una curva de aprendizaje de ~30 minutos, estar en una computadora en lugar de un teléfono, y escribir unos cuantos comandos.

2Instalación

Vas a instalar dos programas gratuitos (VS Code y Claude Code) y a conectarlos con tu cuenta de pago de Claude Pro. Cada paso tiene un punto de verificación para que sepas que vas por buen camino — y este paso termina con Claude Code funcionando de verdad.

2.1 Consigue Claude Pro

  1. Ve a claude.ai → crea una cuenta → Settings → Upgrade to Pro (~$20/mes)

✅ Punto de verificación: "Pro" es visible en tu cuenta

2.2 Instala Visual Studio Code

Windows

  1. Descárgalo desde code.visualstudio.com (solo el sitio oficial)
  2. Elige User Installer, 64-bit (no se requieren permisos de administrador)
  3. En la pantalla de casillas: deja marcada la opción "Add to PATH"; marca las opciones de menú contextual "Open with Code"
  4. Primer inicio: cierra el recorrido de bienvenida y ubícate: Explorer (izquierda), Editor (centro), panel de Terminal (abajo), barra de estado (hasta abajo)

Mac

  1. Descárgalo desde code.visualstudio.com (solo el sitio oficial) — elige la versión para Mac
  2. Abre el archivo descargado y arrastra Visual Studio Code a tu carpeta Applications
  3. Ábrelo desde Applications (o Spotlight — Cmd+Space, y escribe "Visual Studio Code"). La primera vez, macOS puede pedirte que confirmes que confías en él — haz clic en Open
  4. Primer inicio: cierra el recorrido de bienvenida y ubícate: Explorer (izquierda), Editor (centro), panel de Terminal (abajo), barra de estado (hasta abajo) — el mismo diseño que en Windows

✅ Punto de verificación: VS Code abre sin problemas

Opcional: extensiones recomendadas de VS Code

Las extensiones son pequeños complementos — como apps para tu teléfono. No necesitas ninguna de ellas para terminar esta lección; vuelve una vez que Claude Code esté funcionando. Presiona Ctrl+Shift+X (Windows) / Cmd+Shift+X (Mac) → busca por nombre → haz clic en Install → Reload si se te solicita.

2.3 Instala Claude Code

Windows

  1. Abre Windows PowerShell (menú Start → escribe "PowerShell"). No se necesitan permisos de administrador.
  2. Ejecuta:
irm https://claude.ai/install.ps1 | iex

Es normal ver texto desplazándose y una barra de progreso de descarga — eso significa que está funcionando, no que se trabó. Cierra PowerShell y abre una ventana completamente nueva cuando termine; la configuración solo aplica a las terminales abiertas después.

Mac

  1. Abre Terminal (Cmd+Space, escribe "Terminal"). No se necesitan permisos de administrador.
  2. Ejecuta:
curl -fsSL https://claude.ai/install.sh | bash

Es normal ver texto desplazándose y una barra de progreso de descarga — eso significa que está funcionando, no que se trabó. Cierra Terminal y abre una ventana completamente nueva cuando termine; la configuración solo aplica a las terminales abiertas después.

Opcional: instala también Git

No es necesario para esta lección.

Windows

Git for Windows agrega Git Bash, una terminal alternativa, a tu computadora.

  1. Descárgalo desde git-scm.com/downloads/win y acepta todas las opciones predeterminadas

✅ Punto de verificación: "Git Bash" aparece en el menú Start

Mac

Git viene incluido con Xcode Command Line Tools, no es una descarga aparte. Ejecuta git --version en Terminal — si no está instalado, macOS te pedirá instalar las Command Line Tools automáticamente.

✅ Punto de verificación: git --version muestra un número de versión

2.4 Primera ejecución — di hola

  1. En tu nueva ventana de terminal, escribe claude, presiona Enter
  2. Elige Claude.ai account login (no "API key")
  3. Se abre un navegador → inicia sesión → aprueba → regresa a la terminal
  4. Escribe hello y presiona Enter

Está Funcionando

Eso es Claude Code, en vivo, en tu terminal, por primera vez. Todo lo que sigue es simplemente apuntarlo hacia trabajo real.

3Fundamentos de la Terminal

Usa Solo Esta

Para todo en esta guía, usa la Terminal Integrada de VS Code — ábrela con Ctrl + ` (la tecla de acento grave, arriba a la izquierda en tu teclado). Nunca necesitas abrir un programa de terminal aparte. Solo necesitas seis comandos, y ya usaste el más importante — claude — en el paso anterior.

Otras terminales (contexto opcional)
Windows PowerShellShell moderna predeterminada de WindowsSolo para la instalación (Paso 2)
Git BashShell estilo Unix de Git for WindowsAlternativa opcional
Command Prompt (cmd.exe)Shell heredada de WindowsEvítala
Windows TerminalApp de terminal con pestañas de MicrosoftOpcional, un mejor anfitrión para PowerShell
Terminal.app (Mac)Shell integrada de macOS (zsh)Preinstalada, no hay nada que agregar

Los seis comandos

pwd¿Dónde estoy? (igual en Windows y Mac)
dir (PowerShell) / ls (Git Bash y Mac Terminal)¿Qué hay en esta carpeta?
cd nombredecarpetaEntra a una carpeta (igual en Windows y Mac)
cd ..Sube un nivel (igual en Windows y Mac)
cls (PowerShell) / clear (Git Bash y Mac Terminal)Limpia la pantalla
Ctrl + CDetiene lo que se esté ejecutando (igual en Windows y Mac)
Consejos de Supervivencia

Nada se ejecuta hasta que presionas Enter. La flecha hacia arriba recupera tu último comando. Tab autocompleta los nombres. Un error de tipeo solo produce un mensaje de error — no daña nada.

4Tu Primera Tarea

El único concepto: la carpeta del proyecto

Claude solo puede ver y tocar los archivos de la carpeta que abres — una función de seguridad y confidencialidad. Crea una carpeta de prueba, por ejemplo Documents\claude-practice en Windows o ~/Documents/claude-practice en Mac, con 3 a 5 documentos de muestra no confidenciales.

Abre la carpeta

  1. File → Open Folder → selecciona claude-practice (o clic derecho en la carpeta → "Open with Code")
  2. Aprueba el aviso "Trust the authors"
  3. Recorre la barra lateral de Explorer
  4. Abre la terminal (Ctrl + `) y escribe claude de nuevo — las sesiones están acotadas a la carpeta en la que estás, así que esto inicia una nueva aquí

Cómo trabajar con archivos de Word, PDF y Excel

Funciona de forma nativa y sin problemas: texto plano, Markdown (.md), .csv, .txt. Funciona con salvedades: PDFs (se pueden leer, no editar directamente), .docx (se puede leer, pero el formato se comprime). Flujo de trabajo recomendado: trabaja en Markdown, exporta a Word/PDF al final — pídele a Claude que convierta el contenido de .docx/PDF a Markdown como primer paso de un proyecto.

Ejercicio 1 — haz una pregunta (solo lectura, riesgo cero)

¿Qué documentos hay en esta carpeta, y de qué trata cada uno?

Escribes oraciones normales, no comandos. Ese es el cambio mental clave.

Ejercicio 2 — haz que Claude cree un archivo

Lee todos los documentos de esta carpeta y crea un archivo llamado summary.md con un resumen de un párrafo de cada uno.

La solicitud de permiso: Claude pregunta antes de escribir. Las opciones son permitir una vez, permitir siempre, o denegar. Este es el concepto de seguridad más importante de esta guía. Observa cómo aparece el nuevo archivo en la barra lateral de Explorer.

Eso Es un Archivo Real y Guardado

Claude leyó tus documentos y escribió algo nuevo en el disco — sin copiar y pegar. Ese es exactamente el cambio hacia el que ha apuntado este curso.

¿Quieres ir más allá? Dos ejercicios más

Ejercicio 3 — haz que Claude edite, y revisa el diff

Agrega una sección "Riesgos Clave" a summary.md con tres viñetas.

Revisa la vista de diff — un antes/después lado a lado — y apruébala o recházala. Para Legal, esto es un redline de los cambios que propone la IA. Nada se aplica sin tu aprobación. Claude propone; tú decides.

Ejercicio 4 — la tarea masiva (el verdadero beneficio)

Para cada documento de esta carpeta, extrae el título, la fecha y el tema principal, y colócalos todos en una sola tabla en index.csv.

Abre el resultado con un visor de hojas de cálculo. Esa fue una sola instrucción — en la versión web, habría sido una subida y un prompt por cada documento.

Modo Plan — tu mejor salvaguarda: Claude solo puede leer y pensar, no cambiar nada, hasta que apruebes un plan escrito. Actívalo con Shift+Tab (dos veces, igual en Windows y Mac) o /plan. Se recomienda como tu postura inicial predeterminada para cualquier cosa que toque trabajo real.

5Qué Sigue

CLAUDE.md — enséñale tus estándares a Claude una sola vez

Un archivo de texto plano en la carpeta que Claude lee automáticamente en cada sesión:

  • Marketing: voz de marca, palabras prohibidas, nomenclatura de producto aprobada, nivel de lectura
  • RR. HH.: avisos legales obligatorios, guía de tono, estructura de plantillas, reglas de lenguaje inclusivo
  • Legal: términos definidos, formato de citas, jurisdicción, señalización de lenguaje de indemnización/responsabilidad
  • Ingeniería Industrial: terminología de proceso (takt time, OEE, cambio de formato), estructura de plantillas de SOP, unidades de medida
  • Relaciones Internacionales: temas prioritarios, mapeo de departamentos responsables, convenciones de protocolo y tono

Intenta escribir un CLAUDE.md de cinco líneas y observa cómo cambia la siguiente respuesta.

Comandos slash esenciales

Para salir: /exit, o presiona Ctrl+C dos veces (igual en Windows y Mac).

Cómo hablarle a Claude de forma efectiva

Nombra el qué y el dónde — nombra el archivo. Una tarea a la vez. Di cómo se ve "terminado" (formato, extensión, audiencia). Usa @nombredearchivo para señalar un documento específico. Si el resultado está mal, simplemente dilo con tus propias palabras.

VagoEspecífico
"Mejora esto""Acorta esto a 150 palabras, mantén el mismo llamado a la acción"
"Revisa estos contratos""Señala cualquier cláusula de indemnización que limite la responsabilidad por debajo de $1M"
"Arregla los currículums""Estandariza el formato de fecha de cada currículum a MM/AAAA"
"Resume esto""Resume en 3 viñetas, escrito para un vicepresidente no técnico"

Prompts de ejemplo por rol — el tipo de solicitudes de una línea que muestran cómo se ve "específico" en el trabajo real:

  • RR. HH.: "Lee la hoja de cálculo de currículums en esta carpeta y señala a cualquier candidato que lleve más de 10 días en 'Entrevista Programada'."
  • Legal: "Compara la cláusula de indemnización en todos los contratos de esta carpeta y señala cualquiera que limite la responsabilidad por debajo de $1M."
  • Marketing: "Lee el CSV de desempeño de campaña y dime qué canal tuvo la tasa de clics más alta."
  • Ingeniería Industrial: "Lee la carpeta de reportes de turno y señala cualquier línea de producción con más de 30 minutos de tiempo de inactividad no planificado esta semana."
  • Relaciones Internacionales: "Lee los cables de esta carpeta y señala cualquiera que mencione cooperación comercial, seguridad regional o intercambio cultural."

Límites de uso

Claude Pro tiene límites de sesión continuos de ~5 horas, más límites semanales. Claude Code y el chat de claude.ai comparten el mismo total de uso. Usa /clear entre tareas no relacionadas, evita apuntar a carpetas innecesariamente grandes, y revisa tu uso en cualquier momento en Settings → Usage en claude.ai.

Seguridad, confidencialidad y buenos hábitos

Siempre

  • Lee el diff antes de aprobar
  • Empieza en Modo Plan para cualquier cosa real
  • Acota bien el alcance — abre la carpeta específica del proyecto, nunca la raíz de Documents o Desktop
  • Mantén un respaldo antes de cualquier operación masiva

Nunca

  • Pegar contraseñas, claves de API o datos bancarios
  • Procesar información personal de empleados, datos salariales, expedientes de investigación o material privilegiado de clientes en un plan Pro personal sin la aprobación de tu empleador
  • Aprobar cambios que no entiendes — en su lugar, pídele a Claude que te los explique

Instalación Completa

Pusiste Claude Code a funcionar por primera vez y lograste que produjera un archivo real y guardado — sin un solo copiar y pegar. Ese es el cambio completo. Úsalo en tu propio trabajo real (no confidencial) esta semana.
