Resumen Diario de Correo y Calendario

Conecta Claude Code a tu bandeja de entrada y calendario, y luego lee un solo resumen matutino en lugar de dos apps.

20–25 MIN OBLIGATORIO
1. Conecta Correo y Calendario 2. Dicta lo que Necesitas 3. Construye el Skill 4. Programación Opcional

Esta lección conecta Claude Code a tu correo y calendario reales, y luego construye un skill que lee ambos y te entrega un solo resumen estructurado: el horario de hoy, qué saber antes de cada reunión, y cualquier cosa urgente en tu bandeja de entrada. Donde la Lección 4.3 construyó un plugin de tres skills, esta muestra el otro extremo del rango — a veces un solo skill bien construido es todo el trabajo.

La mayoría de las mañanas empiezan abriendo dos apps y armando a mano la misma imagen: qué hay en el calendario, qué necesita respuesta, qué es realmente urgente frente a lo que solo está sin leer. Ese es un patrón que este curso ya cubrió — revisar algo repetitivo y convertirlo en un resumen — aplicado a una fuente de datos que todos ya tienen.

1Conecta un Servidor MCP de Correo y Calendario

Claude Code no tiene acceso integrado a tu correo ni a tu calendario. Necesita una conexión MCP — el mecanismo de la Lección 4.4 — antes de poder leer un solo mensaje o evento.

  1. Identifica tu proveedor: Google Workspace (Gmail + Google Calendar) o Microsoft 365 (Outlook Mail + Outlook Calendar) son los dos más comunes.
  2. Revisa code.claude.com/docs, la configuración de Connectors de claude.ai, o escribe /mcp dentro de Claude Code para ver si ya existe un conector hecho para tu proveedor hoy — la Lección 4.4, Paso 4 cubre qué hacer si todavía no existe.
  3. Agrega el conector usando el patrón claude mcp add --scope user --transport <type> <name> <address> de la Lección 4.4, Paso 3, llenando el nombre y la dirección reales que encontraste.
  4. Aprueba la petición de inicio de sesión que se abre en tu navegador.
  5. Corre /mcp para confirmar que se conectó y ver las herramientas que ofrece.

Consulta Primero con tu Organización

Conectar una herramienta de IA a una cuenta de correo o calendario del trabajo puede necesitar aprobación de TI o seguridad, según la política de tu empleador. Confirma antes de conectar una cuenta del trabajo — una cuenta personal es un lugar más seguro para practicar esta lección primero.

2Dicta lo que "El Día por Delante" Significa para Ti

Con el conector en su lugar, describe el resumen que realmente quieres — en un solo mensaje largo, el mismo enfoque de dictado a configuración de la Lección 4.3.

  1. Crea una carpeta nueva, por ejemplo daily-briefing, y ábrela en Claude Code.
  2. Adapta y envía el ejemplo de dictado de abajo.
  3. Responde cualquier pregunta aclaratoria que haga Claude Code.
  4. Revisa el CLAUDE.md propuesto antes de aprobarlo.
Quiero un resumen diario que junte mi calendario y mi correo para no
tener que revisar dos apps cada mañana. Para el calendario de hoy,
quiero cada reunión listada con la hora, los asistentes, y una línea
sobre qué necesito saber o preparar antes de ella. Para el correo, solo
me importan los mensajes de las últimas 24 horas que estén sin leer o
marcados — resume lo que sea realmente urgente y omite las
notificaciones rutinarias y todo lo que ya está leído. Si un correo es
de alguien que también está en el calendario de hoy, conecta los dos —
menciónalo junto a esa reunión en lugar de como un elemento aparte.
Mantén todo el resumen lo bastante corto como para leerlo en dos
minutos. Configura esto como un proyecto con un README y un CLAUDE.md
que capture estas reglas, y pregúntame lo que necesites primero.

Lo que Claude Code debería producir:

daily-briefing/
├── README.md              Explica el resumen y cómo correrlo
├── CLAUDE.md               Reglas permanentes: qué cuenta como urgente,
│                           qué tan largo debe ser el resumen, cómo
│                           cruzar reuniones y correos
└── output/
    └── todays-briefing.md Dónde llega el resumen de cada día
Mantén Este Simple

No todo flujo de trabajo necesita un plugin de tres skills. Esta lección construye hacia exactamente un skill — la forma debería coincidir con el trabajo, no al revés.

3Construye el Skill de Resumen Diario

Un solo skill, usando tanto las herramientas de calendario como de correo que ofrece tu conector.

  1. Pídele a Claude Code que construya el skill, describiendo su trabajo con precisión (la descripción de abajo está lista para usarse).
  2. Revisa el SKILL.md que produce.
  3. Corre /daily-briefing y compara el resultado con lo que realmente necesitabas saber esta mañana.

Qué decirle a Claude Code que construya:

Construye un skill llamado daily-briefing. Su trabajo: traer los
eventos del calendario de hoy usando la herramienta de calendario, y
traer el correo sin leer o marcado de las últimas 24 horas usando la
herramienta de correo. Cruzar los dos — si el remitente de un correo
también es asistente de una reunión de hoy, mencionar ese correo junto
a esa reunión en lugar de como un elemento aparte. Producir un solo
resumen corto: un bloque de horario listando cada reunión con
asistentes y una línea de preparación, seguido de una lista corta de
cualquier cosa urgente que quede en el correo sin relación a una
reunión. Guardarlo en output/todays-briefing.md y mostrármelo.

Lo que esto produce (skills/daily-briefing/SKILL.md, resumido):

---
name: daily-briefing
description: Pull today's calendar and recent email into one morning
briefing, cross-referencing meeting attendees with email senders. Use
when the user says "give me my briefing," "what's today look like,"
or "/daily-briefing."
---

# daily-briefing

1. Fetch today's calendar events using the connected calendar tool.
2. Fetch email from the last 24 hours that is unread or flagged, using
   the connected email tool.
3. For each meeting, check whether any attendee also sent a fetched
   email. If so, fold a one-line summary of that email into that
   meeting's entry instead of listing it separately.
4. Write the schedule block: time, attendees, and one prep line per
   meeting.
5. Write a short "Flagged in Email" section for anything urgent that
   didn't tie to a meeting.
6. Save the result to output/todays-briefing.md and display it.

Salida de muestra:

Resumen de Hoy — Martes

09:00 — Revisión de Presupuesto (con Marcus Chen, Priya Nair)
Marcus escribió anoche pidiendo adelantar las cifras del Q3 en la
agenda — vale la pena confirmarlo antes de que empiece la reunión.

11:30 — Llamada con Proveedor (con externo: Aria Logistics)
Sin correo relacionado. Primera llamada con este proveedor — todavía
sin historial.

Marcado en el Correo
- TI: se requiere restablecer la contraseña antes de fin de semana (sin relación a una reunión)
Qué Hizo Esto Rápido

El paso de cruce — conectar el correo de Marcus con la reunión de las 9:00 — es todo el valor de pedirle a un solo skill que mire dos fuentes juntas en lugar de revisar cada app por separado.

4Opcional — Ejecútalo Automáticamente Cada Mañana

Todo lo de arriba todavía requiere abrir Claude Code y escribir /daily-briefing. Este paso es opcional: corre el resumen antes de que te sientes.

Windows

  1. Antes de continuar, revisa de nuevo la Lección 4.1, Paso 4 — confirma que confías en el resultado de /daily-briefing tras varias ejecuciones manuales primero.
  2. Abre Windows Task Scheduler (Programador de tareas).
  3. Crea una tarea básica configurada para correr a diario, por ejemplo a las 7:00 AM.
  4. Apunta la acción al comando de abajo.
claude -p "/daily-briefing" --cwd "C:\path\to\daily-briefing"

Mac

  1. Antes de continuar, revisa de nuevo la Lección 4.1, Paso 4 — confirma que confías en el resultado de /daily-briefing tras varias ejecuciones manuales primero.
  2. Abre Terminal y corre crontab -e (se abre en el editor nano por defecto).
  3. Agrega la línea de abajo para una ejecución diaria a las 7:00 AM, y guarda (Ctrl+O, Enter, Ctrl+X en nano).
0 7 * * * claude -p "/daily-briefing" --cwd "$HOME/daily-briefing"
Mac: Otorga Full Disk Access

Las tareas de cron en macOS suelen fallar en silencio a menos que la app de terminal que las corre tenga Full Disk Access (Acceso completo al disco). Ve a System Settings → Privacy & Security → Full Disk Access y actívalo para Terminal (o tu app de terminal).

Este Paso Es Opcional

Escribir /daily-briefing tú mismo cada mañana ya funciona. Solo automatiza esto si específicamente quieres que el archivo esté listo antes de que te sientes.

Cómo Apagarlo

En Windows: abre Windows Task Scheduler, busca la tarea por su nombre, y Disable o Delete — las mismas dos opciones de la Lección 4.3, Paso 6. En Mac: corre crontab -e y elimina o comenta la línea. Tu servidor MCP conectado y tus reglas de CLAUDE.md quedan intactos en cualquier caso.

Verificación

Un conector MCP de correo y calendario está agregado y confirmado funcionando con /mcp
La carpeta del proyecto tiene un README.md y un CLAUDE.md que describen tus reglas de resumen
/daily-briefing corre y produce un resumen que cruza correctamente al menos una reunión y un correo
¿No Funciona?

Si no se encuentra la herramienta de calendario o correo, confirma que el conector aparece como conectado en /mcp y que reiniciaste Claude Code después de agregarlo. La Lección 4.4 cubre esta conexión por completo si te la saltaste.

Lección completada

Conectaste Claude Code a datos reales y en vivo fuera de tus archivos por primera vez, y construiste un skill que lee dos fuentes juntas. Antes de construir un plugin de varios skills la próxima vez, pregúntate si el trabajo es en realidad un solo paso bien hecho — el skill único de esta lección reemplazó dos apps y un cruce mental, y esa fue toda la ganancia.
