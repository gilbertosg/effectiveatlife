04 OBLIGATORIO

Automatiza Flujos de Trabajo con Claude Code

Enseña a Claude Code a leer y escribir archivos nativos de Office, a conectarse a sistemas en vivo, y a encadenar varios pasos en un solo flujo de trabajo repetible y automatizado — hábitos diarios que lo hacen sostenible, además de un plugin empaquetado y reutilizable para que una tarea recurrente se ejecute igual cada vez que la invocas.

3–3.5 horas 7 lecciones RR. HH. · Ingeniería Industrial · Relaciones Internacionales · Legal · Marketing

Al terminar, podrás

  • › Tener los hábitos diarios — higiene de sesión, revisión rápida de diffs, conciencia de uso — que hacen que Claude Code sea sostenible antes de automatizar nada
  • › Agregar los skills de documentos de Anthropic para que Claude Code pueda leer y escribir archivos .docx, .pdf y .pptx reales
  • › Entender la diferencia entre un skill (una capacidad) y un plugin (varias capacidades empaquetadas juntas)
  • › Entender qué es una conexión MCP y agregar una tú mismo, en claude.ai y en Claude Code
  • › Recorrer una automatización real y completa construida por completo dictando los requisitos y dejando que Claude Code haga la configuración
  • › Conectar Claude Code a tu correo y calendario y generar un resumen diario para el día que tienes por delante
  • › Saber cómo apagar todo lo que construyas — una tarea programada, un plugin, una conexión MCP — no solo cómo encenderlo

Qué Lección Es Para Ti

Solo las Lecciones 4.3, 4.5 y 4.6 están escritas alrededor del ejemplo de un rol específico. Todos los roles deberían completar igualmente 4.1, 4.2 y 4.4 — son los hábitos diarios, los skills de documentos y el concepto de MCP de los que depende cada lección posterior, sin importar el rol.

4.1

Tus Hábitos Diarios con Claude Code

Higiene de sesión, un hábito rápido de revisión de diffs, conciencia de uso, y las cuatro reglas para cualquier cosa que corra sin supervisión.

Las Instrucciones Personalizadas y CLAUDE.md Son la Misma Idea, en Dos Superficies

Las instrucciones personalizadas del Módulo 3 (Proyectos de claude.ai) y el CLAUDE.md de este módulo (Claude Code) cumplen la misma función — reglas permanentes que Claude lee automáticamente en lugar de que tú las repitas — para dos productos distintos. Si usas ambos a diario, esa similitud es deliberada, no una coincidencia: sin importar en qué superficie estés, la solución para "sigo repitiéndome" es la misma.
