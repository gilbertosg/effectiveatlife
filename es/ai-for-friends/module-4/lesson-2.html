Instalando Skills de Anthropic

Agrega cuatro skills en una sola instalación y Claude Code deja de tratar los archivos de Word, PDF y PowerPoint como texto plano.

15 MIN OBLIGATORIO
1. Qué Agrega un Skill 2. Agrega el Marketplace 3. Instala los Skills 4. Verifica

Al terminar esta lección, habrás instalado los skills de procesamiento de documentos de Anthropic y confirmado que Claude Code puede construir un archivo .docx real y abrible. De fábrica, Claude Code puede leer un archivo de Word como texto comprimido y le cuesta escribir uno con el formato correcto. Estos skills arreglan ambas cosas.

La Lección 4.3 termina con Claude Code armando un documento de Word en constante crecimiento — un resumen de acuerdo, un correo de seguimiento, una respuesta, y tus notas, agregados al mismo archivo cada día sin romper su formato. Eso solo funciona si Claude Code tiene primero el skill correcto instalado. Esta lección es ese paso de configuración de una sola vez.

1Qué Agrega un Skill que Claude Code Normal No Tiene

Un archivo .docx, .pptx o .xlsx no es texto plano — es un pequeño archivo comprimido con instrucciones de formato. Sin un skill que le indique cómo, Claude Code igual puede abrir uno, pero lo lee como contenido comprimido y difícil de seguir, y escribir uno nuevo desde cero produce un archivo que muchas veces no abre correctamente en Word o PowerPoint.

Sin el SkillCon el Skill Instalado
Claude Code lee un .docx como contenido crudo y difícil de interpretarClaude Code lee el texto, las tablas y los encabezados con su formato real
Un archivo de Word nuevo que escribe Claude Code suele tener el formato roto o no abre bienUn archivo de Word nuevo abre correctamente, con encabezados, tablas y configuración de página reales
Los PDF se pueden leer pero no se puede extraer nada de forma limpiaEl texto y las tablas simples se extraen de forma limpia de un PDF
Las presentaciones de PowerPoint casi no sirven como entrada ni como salidaClaude Code puede leer el contenido de las diapositivas y construir una presentación con el formato correcto
Un Plugin, Cuatro Skills

Anthropic empaqueta docx, pdf, pptx y xlsx juntos como un solo plugin llamado document-skills. Lo instalas una vez y obtienes los cuatro.

Esto Es Opcional Hasta Que lo Necesites

Si nunca le pides a Claude Code que toque un archivo de Word, PDF o PowerPoint, no necesitas esto. La Lección 4.3 lo necesita para su paso del documento de Word, así que instálalo ahora si piensas hacer esa lección.

2Agrega el Marketplace de Skills de Anthropic

Claude Code no viene con todos los skills posibles preinstalados. Los skills vienen de un marketplace — un catálogo de plugins instalables — y apuntas Claude Code a uno antes de poder instalar algo de ahí.

  1. Abre Claude Code en una terminal (cualquier carpeta de proyecto sirve para este paso).
  2. Escribe el comando de abajo y presiona Enter.
  3. Espera a que Claude Code confirme que el marketplace se agregó.
/plugin marketplace add anthropics/skills

Lo que deberías ver:

Marketplace "anthropic-agent-skills" added.
Run /plugin install <name>@anthropic-agent-skills to install a plugin from it.
Paso de Una Sola Vez

Solo necesitas agregar un marketplace dado una vez por computadora. Cada sesión futura de Claude Code ya lo conoce.

Solo Agrega Marketplaces en los que Confíes

Un marketplace es un catálogo de instrucciones que Claude Code va a seguir. anthropics/skills es el repositorio oficial del propio Anthropic. No agregues un marketplace de una fuente desconocida sin consultarlo antes con tu equipo de TI o de seguridad.

3Instala los Skills de Documentos

Con el marketplace agregado, instalar los skills reales es un comando más.

  1. En la misma sesión de Claude Code, escribe el comando de instalación de abajo.
  2. Presiona Enter y espera la confirmación.
  3. Reinicia Claude Code (cierra y vuelve a abrir tu terminal, o empieza una sesión nueva) para que los skills nuevos se carguen.
/plugin install document-skills@anthropic-agent-skills

Lo que deberías ver:

Installed "document-skills" (docx, pdf, pptx, xlsx).
Restart Claude Code for the new skills to take effect.
Revisa Qué Está Instalado

Escribe /plugin en cualquier momento para ver una lista de cada marketplace y plugin instalado actualmente en tu computadora.

4Verifica que Funcionó

La forma más rápida de comprobar que un skill está activo es pedirle a Claude Code que lo use.

  1. Abre una carpeta de proyecto en Claude Code (cualquier carpeta — esto es solo una prueba).
  2. Escribe el prompt de abajo.
  3. Abre el archivo resultante en Word (o un visor que soporte .docx) y confirma que se ve como un documento real, no con el formato roto.
Create a one-page Word document called skill-test.docx with a title,
"Skill Test," and three bullet points describing what you can now do
with Word files that you couldn't do before this skill was installed.

Lo que deberías ver: aparece un archivo real skill-test.docx en la barra lateral del Explorador de tu carpeta de proyecto. Al abrirlo se ve un título con formato y tres viñetas — no un muro de XML ni texto roto.

Si No Funcionó

Confirma que reiniciaste Claude Code después del Paso 3. Los skills se cargan al iniciar la sesión, no a mitad de ella.

Verificación

/plugin marketplace add anthropics/skills se completó sin error
/plugin install document-skills@anthropic-agent-skills se completó y reiniciaste Claude Code
Claude Code construyó un archivo skill-test.docx que abre correctamente con el formato real
¿No Funciona?

Si el archivo de prueba no abre o se ve roto, confirma que la instalación se completó en el Paso 3 y que reiniciaste la sesión. Si sigue fallando, corre /doctor y revisa la salida en busca de un error relacionado con el plugin.

Lección completada

Claude Code ahora puede leer y escribir archivos reales de Word, PDF y PowerPoint — todo lo que necesita el paso del documento de Word de la Lección 4.3. Elimina skill-test.docx una vez que hayas confirmado que abre correctamente; solo estaba ahí para probar que la instalación funcionó.
