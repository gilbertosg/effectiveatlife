¿Qué Es un Servidor MCP?

El único concepto que le permite a Claude ir más allá de tus archivos y chats, hacia tus cuentas reales y en vivo — en la web y en Claude Code.

20 MIN OBLIGATORIO
1. El Concepto 2. Conectores en claude.ai 3. MCP en Claude Code 4. Revisar y Eliminar

La Lección 1.1 definió MCP en una línea: "una conexión en vivo entre tu asistente de IA y otra app o sistema." Esta lección lo hace concreto. Verás exactamente cómo se ve una conexión MCP en claude.ai y en Claude Code, agregarás una tú mismo, y aprenderás los límites honestos de lo que está disponible hoy — antes de que la Lección 4.5 te pida conectar tu correo y calendario.

Cada lección de este módulo hasta ahora trabajó con cosas que Claude Code ya puede alcanzar por su cuenta: archivos en una carpeta, una página web pública. Tu correo, tu calendario, y la mayoría de las demás cuentas reales no son alcanzables de esa forma. Una conexión MCP es el único mecanismo que cambia eso — y vale la pena entenderlo a propósito, una vez, en lugar de irlo recogiendo en pedazos de un comando que te dicen que copies.

1El Concepto, Hecho Concreto

Un servidor MCP es un puente. De un lado está Claude — en claude.ai o en Claude Code. Del otro lado hay un sistema real: tu correo, tu calendario, una base de datos, un gestor de proyectos. MCP es el protocolo que deja que los dos se comuniquen, para que Claude pueda leer datos reales y actuales en lugar de adivinar a partir de lo que aprendió en su entrenamiento.

Esto No Es lo Mismo que Subir un Archivo

Subir un archivo a un Proyecto (Lección 3.4) es una foto de un solo momento. Una conexión MCP está en vivo — Claude lee el estado actual del sistema cada vez, no una copia que hiciste una vez.

2Agregar un Conector en claude.ai

En la web, las conexiones MCP se llaman Conectores. Esta es la forma sin terminal, basada en clics, de darle a Claude acceso a una app real.

  1. En claude.ai, abre Settings y busca una sección de Connectors (a veces llamada Integrations). Los nombres de menú y las ubicaciones exactas cambian con el tiempo — si no está donde dice esta lección, busca "connector" en Settings o revisa la ubicación actual en el centro de ayuda de claude.ai.
  2. Explora los conectores disponibles. Lo que se ofrece cambia con el tiempo y según el plan (Free, Pro, Team, Enterprise) — revisa lo que realmente aparece listado para tu cuenta en lugar de asumir que una app específica está ahí.
  3. Para conectar uno, haz clic en él y completa el flujo de inicio de sesión — esto es un inicio de sesión OAuth estándar en tu propia cuenta, el mismo tipo de flujo de "Iniciar sesión con Google" que has usado en otros lados. No estás compartiendo una contraseña con Claude.
  4. Si usas Proyectos de claude.ai (Módulo 3), revisa si un conector se puede limitar a un Proyecto específico en lugar de a toda tu cuenta — esto determina si un Proyecto que tiene un conector activado ahora puede alcanzar esa app en vivo, corrigiendo un punto de la Lección 3.4.
Verifica lo Actual, No Confíes en una Captura de Pantalla

Qué apps tienen un conector ya hecho, y si un conector dado está disponible en tu plan específico, ambas cosas cambian con el tiempo. Esta lección deliberadamente no promete una lista fija — revisa Settings en tu propia cuenta para la respuesta real y actual.

Corrigiendo la Lección 3.4

La Lección 3.4 decía que un Proyecto no puede alcanzar tu correo ni ninguna otra app o cuenta. Eso era cierto cuando se escribió y sigue describiendo lo que pasa por defecto — nada alcanza un Proyecto automáticamente. La corrección: si activas explícitamente un Conector para un Proyecto, ese Proyecto puede entonces alcanzar esa app conectada de ahí en adelante. La regla central no ha cambiado — tú decides qué puede ver un Proyecto — pero un Conector es ahora una de las formas en que puedes extender ese alcance, no solo un archivo subido.

3Agregar un Servidor MCP en Claude Code

En la terminal, la misma idea tiene un comando en lugar de una página de configuración.

  1. Lee el patrón del comando y las dos opciones de alcance de abajo.
  2. Practica con cualquier servidor MCP para el que tengas una dirección o comando real — si todavía no tienes uno, no practiques y vuelve a este paso cuando la Lección 4.5 te dé uno para agregar.
  3. Usa /mcp dentro de cualquier sesión de Claude Code para ver qué está conectado ahora mismo y qué herramientas ofrece cada conexión.
claude mcp add --transport <type> <name> <address-or-command>
ParteQué Va Ahí
<type>Cómo le habla Claude al servidor: stdio para un programa local que Claude corre él mismo, sse o http para un servidor remoto y alojado al que se llega por dirección
<name>Una etiqueta corta que tú eliges — este se convierte en el nombre mostrado en /mcp
<address-or-command>Una dirección web para sse/http, o el comando que inicia el programa local para stdio

Ejemplo — un servidor remoto y alojado:

claude mcp add --transport sse project-tracker https://mcp.example.com/sse
AlcanceComandoDónde Está Disponible
Proyecto (por defecto)claude mcp add --transport sse project-tracker https://mcp.example.com/sseSolo dentro de la carpeta desde donde lo corriste
Usuario (global)claude mcp add --scope user --transport sse project-tracker https://mcp.example.com/sseCada proyecto de Claude Code en tu computadora
Agrega "--scope user" para Cualquier Cosa que Uses a Diario

Si una conexión es específica del trabajo de un proyecto (una base de datos que solo toca ese proyecto), déjala con alcance de proyecto. Si es algo que quieres en cada sesión — tu correo, tu calendario — agrega --scope user para no repetir la configuración por proyecto.

La primera vez que usas una conexión que necesita un inicio de sesión, se abre una ventana del navegador para el mismo tipo de inicio de sesión OAuth del Paso 2 — estás aprobando el acceso de Claude Code a tu cuenta, no entregando una contraseña.

/mcp

Correr esto dentro de cualquier sesión lista cada servidor conectado y las herramientas que ofrece — tu primera parada cada vez que algo no funciona.

La Alternativa del Archivo

Los usuarios avanzados también pueden definir servidores MCP directamente en el archivo .mcp.json de un proyecto, o de forma global en ~/.claude.json, en lugar de usar el comando add. Para una primera conexión MCP de Claude Code, el comando de arriba es el camino más simple — los archivos existen principalmente para que todo un equipo pueda registrar un .mcp.json compartido en control de versiones y obtener las mismas conexiones automáticamente.

4Revisar, Eliminar, y Ser Honesto Sobre lo que Existe

Antes de que la Lección 4.5 te pida conectar tu correo y calendario reales, una advertencia honesta y una tarea de mantenimiento.

  1. Lee la advertencia de abajo antes de asumir que una app específica tiene un conector de una sola línea, ya hecho.
  2. Para eliminar una conexión en Claude Code, pídeselo directamente a Claude — "elimina el servidor MCP project-tracker" — y confirma lo que propone, o revisa /mcp para el comando exacto de eliminación que reporta.
  3. Para eliminar un Conector en claude.ai, vuelve a Settings → Connectors y desconéctalo de la misma forma en que revocarías el acceso de cualquier otra conexión tipo "Iniciar sesión con Google."
No Toda App Tiene un Conector Propio, Ya Hecho

Anthropic, Google y Microsoft publican algunos conectores MCP alojados, y la lista crece con el tiempo — pero no hay garantía de que ya exista un conector propio, de una línea, para cada app específica, incluyendo algunas importantes como Gmail u Outlook. Si Settings → Connectors o una dirección documentada no muestra lo que necesitas, eso es un vacío real, no algo que estés haciendo mal. La Lección 4.5 te muestra dónde revisar el estado actual antes de asumir que el acceso existe.

Esto Cambia Más Rápido que Este Curso

La disponibilidad de conectores es una de las partes de Claude que más rápido cambia. Trata lo que encuentres en Settings o en la documentación el día que leas esto como la respuesta real — no cualquier nombre o dirección específica impresa en un curso como este.

¿No Funciona?

Si /mcp no muestra nada después de agregar un servidor, confirma que reiniciaste Claude Code y que la dirección o comando que usaste es correcto — un error de tipeo en una dirección es la causa más común.
