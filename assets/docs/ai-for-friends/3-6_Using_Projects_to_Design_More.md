## Overview

By the end of this lesson, you will use a working Project to design your next one. Once your first Project works well, you do not start the second from scratch. You ask Claude to draft the name, description, instructions, and file list for you.

### Why This Matters

A working Project already knows your role and your formatting preferences. That makes it the best tool for designing the next Project, because its suggestions arrive pre-fitted to how you work. You get a complete setup to paste in, instead of a blank instructions field to fill alone.

### Prerequisites

- [Lesson 3.4: Giving Your Project Reference Material](3-4_Project_Material.md)
- One working Project you have already set up

### Time to Complete

## Step 1: Have Claude Design the Next Project

Your first working Project can design your next one. Ask it for the full setup in a pasteable format, and it drafts the name, description, custom instructions, and reference-file list for you.

### What You'll Do

You will run a design prompt inside your existing Project and get a complete setup for a new one.

### Instructions

1. Open your existing, working Project.
2. Start a new chat inside it.
3. Paste the prompt below, editing the goal to match the Project you want.
4. Read the four-part setup Claude returns.

### The Design Prompt

```text
I want a new Project that drafts weekly status summaries for my team.
Design it for me. Give me the exact: (1) Project name, (2) short
description, (3) custom instructions, and (4) a list of reference
documents I should upload as Project knowledge. Write the custom
instructions so I can paste them straight into a new Project.
```

## Step 2: Pick Your Next Project

The design prompt works best with a clear target. This step gives you five proven Project ideas. Pick one, run the prompt from Step 1, and build it using the lessons you have already completed.

### What You'll Do

You will choose one new Project to build and create it using the design prompt and the earlier lessons in this module.

### Instructions

1. Pick one Project from the table below.
2. Run the Step 1 design prompt with that Project as the goal.
3. Create the Project, following [Lesson 3.3](3-3_First_Project.md).
4. Upload the suggested files, following [Lesson 3.4](3-4_Project_Material.md).

### Example Projects Worth Building

| Project Name | Purpose | What it would need |
|------------|---------|--------------------|
| Weekly-Reporter | Turns your notes into a weekly status summary | Your status-report template as Project knowledge |
| Feedback-Tracker | Spots recurring themes in client or employee feedback | A folder of past feedback notes to reference |
| Template-Finder | Helps you pick and fill the right document template | All your standard templates uploaded as knowledge |
| Deadline-Monitor | Flags approaching filing or campaign deadlines you paste in | Your standing deadline rules in the custom instructions |
| Meeting-Summarizer | Turns meeting notes into action items | Your preferred action-item format in the instructions |
| Nonconformance-Tracker | Spots recurring defect types across nonconformance reports (Industrial Engineering) | A folder of past nonconformance reports and your report format |
| Cable-Digest | Turns incoming cables or agreements into a briefing-ready summary (International Relations) | Your briefing-memo template and priority-topics list |
