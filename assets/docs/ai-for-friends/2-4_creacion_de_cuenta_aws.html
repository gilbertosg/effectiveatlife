Creación de tu Cuenta AWS

Amazon Web Services (AWS) proporciona las herramientas profesionales para alojar sitios web. Esta guía explica cómo crear tu cuenta desde cero para poder publicar tus proyectos en internet.

15 MIN PASO PREVIO
1. Conceptos Clave 2. Registro Inicial 3. Facturación 4. Verificación 5. Plan de Soporte

1Conceptos Clave antes de empezar

Antes de sumergirnos en el proceso de registro, es importante entender cómo funciona AWS y qué vas a necesitar.

ConceptoLo que significa para ti
Capa Gratuita (Free Tier) AWS ofrece una generosa capa gratuita durante 12 meses para cuentas nuevas. Alojaremos tu página web dentro de estos límites gratuitos, por lo que, en condiciones normales, no deberías pagar nada por alojar un sitio estático básico.
Pago por uso AWS cobra basándose en los recursos que consumes. Si tu sitio web se vuelve inmensamente popular de la noche a la mañana y supera los límites de la capa gratuita, AWS comenzará a cobrarte unos pocos centavos por cada giga de datos transferido.
Requisito de Tarjeta Para crear la cuenta, AWS te pedirá obligatoriamente una tarjeta de crédito o débito. Esto es un estándar en la industria para verificar tu identidad y prevenir la creación de cuentas falsas, así como para tener un método de cobro en caso de que superes la capa gratuita.
Cargos de Verificación Temporales

Al registrar tu tarjeta, AWS podría realizar un cargo temporal muy pequeño (generalmente $1 USD) para verificar que la tarjeta es válida. Este cargo no es real y desaparecerá o será reembolsado a tu cuenta en unos pocos días.

2Registro Inicial

Comencemos creando tus credenciales de acceso para la cuenta raíz (Root User).

  1. Ve a la página oficial de AWS: aws.amazon.com/es/.
  2. Haz clic en el botón naranja que dice "Crear una cuenta de AWS" (Create an AWS Account) situado en la esquina superior derecha.
  3. Dirección de correo electrónico: Ingresa un correo electrónico al que tengas acceso. Si estás creando esto para tu empresa (como Vandelier), usa tu correo corporativo.
  4. Nombre de la cuenta de AWS: Ingresa un nombre para tu cuenta. Esto es solo para tu referencia interna (ej. "MiSitioWeb" o "Vandelier-Produccion"). Puedes cambiar este nombre más tarde.
  5. Haz clic en Verificar dirección de correo electrónico.
  6. AWS te enviará un código numérico a tu correo. Cópialo y pégalo en la pantalla para confirmar que eres el dueño del correo.
  7. Contraseña: Crea una contraseña fuerte y segura. Esta cuenta (conocida como el Usuario Raíz o "Root User") tendrá control total sobre todos los recursos y la facturación, así que asegúrate de guardarla en un lugar seguro.

3Información de Contacto y Facturación

Ahora AWS necesita saber quién eres y cómo manejar posibles futuros cobros.

  1. Información de contacto: Selecciona el tipo de cuenta.
    • Elige "Empresa" (Business) si estás creando esto para tu trabajo o compañía.
    • Elige "Personal" si es para tus propios proyectos. No hay diferencia en las características o precios entre ambas opciones.
  2. Llena el resto del formulario con tu nombre completo, número de teléfono, país y dirección física real. Marca la casilla para aceptar los términos y condiciones, y continúa.
  3. Información de facturación: Ingresa los datos de tu tarjeta de crédito o débito. Como se mencionó anteriormente, esto es obligatorio para verificar tu identidad y para tener un respaldo en caso de que excedas los límites gratuitos.
  4. Ingresa la dirección de facturación asociada a esa tarjeta.
Seguridad de tus Datos

Amazon es una de las empresas de tecnología más grandes y seguras del mundo. Tus datos de facturación se procesan de forma segura y no se comparten. La tarjeta se utiliza como una medida antifraude esencial en la nube.

4Verificación de Identidad

AWS realizará un último paso para confirmar que eres una persona real y no un robot automatizado tratando de crear cuentas masivas.

  1. Se te pedirá que proporciones un número de teléfono válido.
  2. Selecciona cómo prefieres recibir el código de verificación: por mensaje de texto (SMS) o mediante una llamada de voz automatizada.
  3. Ingresa tu número (asegúrate de seleccionar el código de país correcto) y resuelve el código de seguridad (captcha) que aparece en pantalla.
  4. Haz clic en "Enviar SMS" o "Llamarme ahora".
  5. Una vez que recibas el código numérico de 4 dígitos en tu teléfono, ingrésalo en la pantalla de AWS y haz clic en continuar.

5Seleccionar el Plan de Soporte (¡Paso Crítico!)

Este es el paso final, y es donde debes tener cuidado para no suscribirte a un servicio de pago mensual sin quererlo.

AWS ofrece diferentes niveles de soporte técnico. Para nuestros propósitos, y para cualquier persona que esté empezando o alojando proyectos simples, el plan gratuito es más que suficiente.

  1. Verás una pantalla comparando tres planes de soporte: "Basic Support", "Developer Support" y "Business Support".
  2. Paso crítico: Asegúrate de seleccionar "Basic Support - Free" (Soporte básico - Gratuito).
  3. Los planes Developer (desde $29/mes) y Business (desde $100/mes) ofrecen ayuda técnica prioritaria por parte de ingenieros de AWS, pero no los necesitas para seguir los tutoriales de este curso.
  4. Haz clic en el botón naranja "Complete Sign Up" (Completar registro).

¡Y eso es todo! Verás una pantalla de bienvenida felicitándote por crear tu cuenta de AWS. A veces, la activación completa de la cuenta puede tardar un par de minutos, o incluso unas horas en casos raros, mientras AWS procesa tu información.

Ahora puedes hacer clic en "Go to the AWS Management Console" e iniciar sesión con el correo y la contraseña que creaste en el Paso 2.

Verificación

Pudiste iniciar sesión en la Consola de Administración de AWS.
Has guardado tu contraseña de usuario raíz en un lugar seguro.
Entiendes que tu cuenta está protegida por la Capa Gratuita (Free Tier), pero requiere una tarjeta válida por seguridad.

Preparación completada

Tienes las llaves del castillo. Tu cuenta de AWS está lista y configurada para que puedas comenzar a construir y desplegar infraestructura real en la nube.
