Architecture

Seven pillars. One system.

Every action, project, and goal partitions into one of seven mutually exclusive domains — numbered roughly foundation to contribution. Each pillar carries its own key results, tracked with the same rigor as a product roadmap.

L1 DRIVER

Mind & Physical Body

Physical health is the substrate for every other pillar — energy, sleep, and mental peace come first.

e.g. protected sleep window · daily meditation · 3–4 strength sessions / week

L2 ACTIVE

Relationships

Invest in people deliberately — partner, family, close friends don't run on autopilot.

e.g. weekly dedicated time · scheduled family visits · shared long-term planning

L3 DRIVER

Work / Career / Mission

Deep Work on the right problems, not just more work. Career growth and a bounded side-mission.

e.g. 10 hrs/week protected Deep Work · defined promotion path · capped work-week

L4 ACTIVE

Personal Growth

Skills compound, so build them deliberately — not whatever crosses your feed this week.

e.g. ~8 books / year · 1–2 technical courses · weekly synthesis practice

L5 ACTIVE

Finances

Build the floor before reaching for the ceiling — savings rate and cash flow before upside bets.

e.g. fixed savings rate · positive cash-flow streak · credit health maintained

L6 ACTIVE

Hobbies & Life Celebration

Joy isn't earned after work is done — it's what makes the rest of the system sustainable.

e.g. one new hobby commitment · several new-experience trips / year

L7 PASSENGER

Contribute

The system compounds further when it's shared — writing, teaching, publishing what's been learned.

e.g. ~1 public post / month · fixed video cadence · weekend-only time budget

7 / 7

Every pillar has a schema, a set of key results, and a weekly check-in question. Nothing runs on vibes.

Allocation Model

Not every pillar gets equal energy.

Gil OS assigns strict hierarchies to prevent a side project from expanding into the time budget of the primary mission. Two roles, one hard rule.

DRIVER

Primary focus. Gets the majority of time and energy.

Currently Health (L1) and Career (L3). When a Driver pillar demands more, every Passenger track pauses — without exception, and without guilt.

PASSENGER

Secondary focus. Runs on a fixed, time-boxed window.

The Contribute track runs in a single protected weekly window and never competes for time outside it. The constraint is both a ceiling and a protection mechanism.

Execution

Three nested loops keep it running.

Strategy sets the direction once a year. Everything else is a cadence that keeps the system honest.

ANNUAL

Strategy — OKRs

One objective per pillar, set at the start of the year, reviewed quarterly. Every key result ties to a measurable number.

WEEKLY

The Friday Finish

Review the week's habit data, name the Big Rocks for the next one, and schedule Deep Work before the calendar fills itself in.

DAILY

Habit Tracker

A lightweight daily capture — sleep, nutrition, exercise, meditation, reading. Objective data instead of end-of-week memory.
